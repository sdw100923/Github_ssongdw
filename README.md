# 깃허브 커밋 설명서
---
### git init
- git init은 일반 컴퓨터 폴드를 git이 관리하는 로컬 저장소로 변환하거나, 초기화하는 명령어 입니다.  
- init 은 intialize 의 줄임말로, 풀어보면 git 초기화 입니다.  
- 새로운 프로젝트 시작할때 보통 한번만 실행하는 필수 기초 명령어 입니다.
### git add .
- git add . 은 내가 수정한, 새로만든 파일을 Stagining Area(준비 단계)에 올리는 명령어 입니다.  
- git add . 바로 저장하는 것이 아닌, 다음 Commit(커밋)에 포함할 파일을 골라 담는 장바구니와 비슷합니다.
### git commit
- git commit 은 코드의 수정한 내용과 기록을 내 컴퓨터 저장소에 영구적으로 남겨두는 명령어 입니다.
- 버전 만들기 - 코드가 바뀐 특정 순간을 하나의 상태(버전)로 기록합니다.
- 되돌리기 가능 - 문제가 생기면 언제든지 예전 커밋(세이브 포인트)으로 돌아갈 수 있습니다.
- 기록,이력 남기기 - 누가, 언제, 무엇을, 왜 바꿨는지(커밋 메시지) 함께 저장합니다.
### git remote add orgin "링크"
- git remote add orgin 명령어는 내 컴퓨터에 있는 로컬 저장소 깃허브와 같은 원격 저장소(URL)에 연결하고,
- 그 주소의 별명을 origin으로 붙이는 명령어 입니다.
- 긴 URL 주소 대신 origin 이라는 단어로 원격 저장소를 쉽게 부를 수 있습니다
